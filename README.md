# Miltonus

A personal website for writing, creative work, and software projects.

## Vision

Miltonus is the home for my writing and creative work.
The Milton Tribute will be the first published page. *What Odysseus Did* will be the second.
Over time, the website may expand to include fiction, essays, and selected software projects.
The website is intended to remain simple, elegant, easy to maintain, and free to host.
It is hosted on GitHub Pages, with all source code and content owned by the author.
